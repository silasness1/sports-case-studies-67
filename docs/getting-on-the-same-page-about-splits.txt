        nested_cv(data = euro,                          # euro is just all the data together
                  outside = group_vfold_cv(v = 6, 
                                           group = Year,
                                           repeats = 1,
                                           strata = NULL),
                  inside = group_vfold_cv(v = 5, 
                                          group = Year,
                                          repeats = 1,
                                          strata = NULL)) -> nest_folds

PROPOSED PLAN:

1) Pretend we have a hyperparameter, k_i, in {.01,.1,.5}. Model_class, i, in {poisson, nn, xgboost, rf}:

    - We fit each hyperparameter & model_class (3*4 = 12) to all of the training sets (6 outer * 5 inner = 30) 
        12 algorithms*30 resampled sets = 360 different models in this example

2) Average the RMSE performance across the inner folds for the different hyperparameters: 
    - Example (within Outer Layer 5 where 2012 is always missing)

                [1] "layer_1: 5 layer_2: 1"
                [1] 2004 2008 2016 2024            
                [1] "layer_1: 5 layer_2: 2"
                [1] 2004 2008 2016 2020            
                [1] "layer_1: 5 layer_2: 3"
                [1] 2008 2016 2020 2024
                [1] "layer_1: 5 layer_2: 4"
                [1] 2004 2016 2020 2024
                [1] "layer_1: 5 layer_2: 5"
                [1] 2004 2008 2020 2024

    - We have 12 different models fit to each of these guys... 
            - if you're working on random forest (rf) model_class
                    - find the average RMSE over these 5 folds *for each* k_rf in {.01, .1, .5}
        
            You end up with something like this (still specific to Outer Fold 5) 
                
                Random Forest Tuning Results for Outer Fold 5
                k_rf = .01 -> rmse_avg = 2.74
                k_rf = .1  -> rmse_avg = 3.43
                k_rf = .5  -> rmse_avg = 5.12
                       For Outer Fold 5, k_rf = .01 Won!!

                Random Forest Tuning Results for Outer Fold 4
                k_rf = .01 -> rmse_avg = 6.43
                k_rf = .1  -> rmse_avg = 2.63
                k_rf = .5  -> rmse_avg = 4.12
                        For Outer Fold 4, k_rf = .1 won!!


    - So at the end of this step, we'll end up with 6 outer folds * 4 algorithms = 24 to compare!

3) Now we measure the out-of-sample-RMSE for each model_class across the outer folds: 

        - rf:      rmse_avg_across_outer = 6.52
        - nn:      rmse_avg_across_outer = 7.21
        - poisson: rmse_avg_across_outer = 3.12
        - xgboost: rmse_avg_across_outer = 2.12

            Conclusion: xgboost was the best algorithm (including letting tuning be part of the algorithm)

4) Use the best algorithm-inclusive-of-tuning to fit on the entire training data (2004-2024) BUT We still need 
the best hyperparameter now that we're using more data: 

       In the example, xgboost won. 

                So now we use the outer folds to choose the best k_xgboost hyperparameter for final model:

                
                - Simplify the nested structure to just the outer folds:

                        - Outer fold 1: 2016 IS ALWAYS MISSING

                        - Outer fold 6: 2020 IS ALWAYS MISSING
